# Network

Shows this computer’s download and upload speed on the BUSY Bar, next to
UP/DOWN labels.

This is the traffic on your computer right now. It is not a speed test to a
website far away.

Your computer must stay connected. Leave the mode switch on **Off**. This
works on a normal BUSY Bar.

## Start

Open **Start Here** and double-click the Mac or Windows file. The
[main instructions](../../README.md) explain the address, password, and what
to do if Python is missing.

**Back**, moving the mode switch, or closing the window stops it.

If the numbers stay at 0, start a download or upload and look again. The bar
only shows what this computer is doing right then.

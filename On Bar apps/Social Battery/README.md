# Social Battery (on the bar)

Shows how social you feel, from **critical** to **full**. After you install
it, it stays on the bar.

It needs the JavaScript runner described in the
[main instructions](../../README.md). If your bar does not have that, use the
[computer version](../../Computer%20run%20apps/Social%20Battery/) instead. That one
works on a normal BUSY Bar, but the computer has to stay connected.

## Install

Open **Start Here** and double-click the Mac or Windows file.

## Use

1. Turn the mode switch to **Apps** and open **Social Battery**.
2. Press **Start**.

**Dial** moves one level. **OK** or **Start** moves up. **Back** leaves.

It stops at the ends. It does not wrap around. The bar remembers the last
level.

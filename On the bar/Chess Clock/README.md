# Chess Clock

A two-player timer on the BUSY Bar. White is on the left. Black is on the right.

This stays on the bar. It needs the JavaScript runner described in the
[main instructions](../../README.md).

## Install

Open **Start Here** and double-click the Mac or Windows file. The main
instructions explain the address, password, and what to do if Python is
missing.

## Play

1. Turn the mode switch to **Apps** and open **Chess Clock**.
2. In **Setup**, set **Minutes** and **Increment**.
3. Press **Start**. The clocks open paused.

**Start** begins White’s turn, then passes the turn after each move. After
time runs out, **Start** begins a new game.

**OK** pauses or resumes. After time runs out, **OK** does nothing.

**Back** leaves.

Under thirty seconds a clock turns red. At zero it flashes `00:00`, the
status light blinks red, and the back shows who won. A new game turns the
light off.

# AI lessons and skills

## Intent

Busy Bar teaching content is plain Markdown for **any AI tool**:

- **`ai-skills/`** — short, pasteable skills + `BUSY-BAR-CORE.md`
- **`ai-lessons/`** — longer human lessons

## Constraints

1. Keep content tool-agnostic (no editor-specific folders or install steps).
2. Skills are plain Markdown so people can paste or upload them.
3. When firmware/docs change fonts, auth, or draw fields, update `ai-skills/`
   and the matching lesson in the same change.
4. Do not revive outdated BSB-AI Lessons content without verifying against
   current OpenAPI / busylib / firmware.
5. Never teach that Apps mode is required to start host widgets; Off mode is
   fine for `display/draw`.

## Sharing

Tell people: open `ai-skills/BUSY-BAR-CORE.md`, paste into their AI, then ask.
Or share the whole `ai-skills/` folder.

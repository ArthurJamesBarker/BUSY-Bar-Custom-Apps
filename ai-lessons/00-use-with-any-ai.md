# 00 — Use with any AI

These materials are normal Markdown files. They work in ChatGPT, Claude,
Gemini, Copilot, and similar tools.

## Fastest path

1. Open `ai-skills/BUSY-BAR-CORE.md`
2. Copy everything
3. Paste into a new chat
4. Ask for what you want

Example ask:

```
Use the BUSY Bar rules I pasted.
Make a Python script that shows HELLO on the front screen.
I use USB (10.0.4.20).
```

## If the AI supports file upload

Upload:

- `ai-skills/BUSY-BAR-CORE.md`
- optionally the matching skill under `ai-skills/busy-bar-*/SKILL.md`
- optionally lessons from `ai-lessons/` for more detail

## What to share

Share this repository, or just the `ai-skills/` folder. Tell people to paste
`BUSY-BAR-CORE.md` into their AI of choice.

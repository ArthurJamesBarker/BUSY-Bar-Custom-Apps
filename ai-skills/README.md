# BUSY Bar AI skills

These skills are **plain Markdown**. Use them with ChatGPT, Claude, Gemini,
Copilot, or any other assistant that can read a file or pasted text.

## How to use

### Option A — one paste (easiest)

1. Open [BUSY-BAR-CORE.md](BUSY-BAR-CORE.md)
2. Copy all of it
3. Paste into a new chat
4. Then say what you want (example: “Make a Python widget that shows HELLO”)

### Option B — upload files

Upload this whole `ai-skills/` folder, or upload:

- `BUSY-BAR-CORE.md` (always)
- Plus the skill you need, if you want more detail

### Option C — topic skills

| Skill | Use when |
|-------|----------|
| [busy-bar-auth/SKILL.md](busy-bar-auth/SKILL.md) | Wi‑Fi password vs cloud API token, 403 errors |
| [busy-bar-fonts/SKILL.md](busy-bar-fonts/SKILL.md) | Text layout, font names |
| [busy-bar-http-api/SKILL.md](busy-bar-http-api/SKILL.md) | Endpoints, draw/assets, busylib |
| [busy-bar-widgets/SKILL.md](busy-bar-widgets/SKILL.md) | Building a full host widget/app |

Longer human lessons: [`../ai-lessons/`](../ai-lessons/)
